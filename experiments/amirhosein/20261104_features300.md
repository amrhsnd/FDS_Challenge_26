# 300-feature classification pipeline

Each model selects exactly 300 named numeric measurements inside its training fold.
Selection removes all-missing, constant and duplicate columns, ranks remaining
utility using linear coefficients, shallow-tree importance and univariate F scores,
then greedily enforces maximum absolute Pearson correlation of 0.90.

Validation uses five duplicate-aware stratified development folds with the reserved
holdout and matching observation groups excluded. Feature selection, imputation and
scaling are fitted within training folds. Development results are exploratory.
