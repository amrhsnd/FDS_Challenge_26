# Generated artifacts

Write to `outputs/<owner>/<unique-run>/`, e.g.
`outputs/aimilia/20261029_01_team_stats/`. Save predictions, metrics, plots, model
files, and an exact configuration here. These files are ignored by Git; a push does
not back them up. Retain final artifacts in a team-controlled location and describe
how to regenerate them in the experiment record. Only this README is tracked here.
